# Windowed distinct triples on actual zeta zeros

Experiment run on 5 November 2026. A finite-data comparison with exact-half-grid and Haar-unitary controls.

## Outcome

All 18 primary zeta measurements (six bands and three widths) were negative. The 1,001,052-point upper portion of the low-zero table gives means −0.442, −0.444, −0.422 for widths 10, 20, 40. Removing both endpoints of the smallest 1% of gaps, or the densest 5% of windows, preserves negative means in every band.

The high-altitude samples each contain 10,000 zeros. Their magnitudes vary substantially with width and origin. Near zero number 10^21 the width-40 mean changes from −0.580 to −0.030 when the windows shift by half a width. The large low-height sample supports a stable sign. These high-altitude samples leave substantial uncertainty about the limiting magnitude.

Establishing the asymptotic value for zeta, controlling the full exceptional-set contribution in AH, and obtaining the arithmetic evaluation remain open.

## Exact experiment

The six bands were fixed before reading scores.

* Zero indices 1–100,000, 100,001–1,000,000, and 1,000,001–2,001,052.
* The 10,000 zeros immediately after indices 10^12, 10^21, and 10^22.

Unfold using differences of the smooth counting function

\[
\overline N(t)=\frac{t}{2\pi}\left(\log\frac{t}{2\pi}-1\right).
\]

Maintain the original offsets in the high tables. Adding the enormous base to each offset in binary64 would destroy their gaps. The stable relative formula is implemented in `unfold`. Neither local density nor mean spacing is fitted to the observed gaps.

Partition into complete nonoverlapping spatial intervals of width W = 10, 20, 40 in mean-spacing units. Discard partial terminal windows. Within each window use

\[
w(x)=\sin^2(\pi x/W),\qquad 0\le x<W.
\]

For distinct ordered indices define

\[
F(a,b,c)=\sum_{i,j,k\ {\rm distinct}}
w(x_i)w(x_j)w(x_k)
e^{(2\pi i/5)(a x_i+b x_j+c x_k)}.
\]

The window score is

\[
S_W=\frac{\operatorname{Re}\{F(6,1,-7)-F(-4,1,3)\}}{5W/16}.
\]

The fixed denominator is the integral of w^3. Retain it when points are removed. Inclusion–exclusion subtracts all repeated-index terms. The raw product of three traces has additional pair contributions.

Every translated exact half-grid gives S_W = 0, including after arbitrary thinning and with this taper. The phase quotient exp(4πi(x_i−x_k)) equals one on a half-grid.

Windowing changes the observable. Its CUE expectation was separately evaluated by integrating the finite-rank three-point determinant against these weights. At rank 120 the values are −0.4000000150, −0.4000000001, and −0.4000000000. An independent three-dimensional quadrature checks the Fourier-trace evaluation.

The compact physical-space Hann window has Fourier tails. A future proof using a restricted Fourier-support theorem must control or replace those tails.

## Controls

* CUE uses 2,400 independent Haar matrices in U(120), generated by SciPy's Haar sampler. Eigenphases unfold to a circle of circumference 120.
* ACUE uses 80 independent rank-120 projection determinantal samples on 240 half-grid sites, with a uniform common rotation. Conditional projection-kernel sampling gives the Vandermonde-squared law.
* Every width divides 120. Windows never cross independent realizations.
* Seeds are 20261105 for CUE and 20261106 for ACUE.
* ACUE grand means are within 3e−13 of zero. The largest absolute single-window residual is below 5e−11.
* Each CUE Monte Carlo mean is within two reported standard errors of its independently computed expectation.

Controls use the same statistic, widths, taper, spatial normalization and trimming definitions as the zero data.

## Crowding and window sensitivity

The first two deletions were specified before computing the scores. The last two were added as sensitivity checks after the first run.

1. **Endpoint deletion.** Rank consecutive gaps within each band. Flag both endpoints of the smallest floor(1% of gap count) gaps. Recompute each score, dropping every triple containing a flagged point. Retain positions, windows and denominators.
2. **Dense-window deletion.** Rank windows by occupancy. Remove the highest 5%. Ties at the cutoff receive equal fractional retention so exactly 95% of window weight remains.
3. **Whole-window deletion.** Discard any window containing a flagged endpoint from step 1. At width 20 this removes approximately 18–19% of zeta windows.
4. **Origin shift.** Translate the window origin by W/2 and repeat. CUE/ACUE points rotate within their original circle to avoid mixing independent matrices.

Trimming selects a different population. Compare trimmed zeta with identically trimmed controls. A surviving negative score supports robustness to these specified deletions. Bounding every possible exceptional set in an asymptotic hypothesis requires additional work.

## Error bars

The CSV standard errors use 40 disjoint contiguous spatial batches per band. Control batches comprise whole independent matrices. A weighted-ratio estimator uses the same batch method after trimming. The chart shows mean ± 2 SE.

Zeta windows are correlated, and the heights are a small fixed collection of published tables. These bars describe observed batch variability. Rigorous confidence intervals and hypothesis-test p-values would require additional assumptions. Windows were never selected by score sign. Low-height deviations from −0.4 are appreciable relative to batch variability, and their cause remains unidentified.

## Sources and precision

Download URLs and SHA-256 hashes are fixed in `run.py`. Raw tables are cached outside this repository.

* [Odlyzko's original tables](https://www-users.cse.umn.edu/~odlyzko/zeta_tables/).
* `zeros6.gz` contains 2,001,052 entries with stated accuracy 4e−9.
* `zeros3` contains the 10^12 band, with accuracy guaranteed to 1e−8 by its header.
* `zeros4` and `zeros5` contain the 10^21 and 10^22 bands. Their headers state unguaranteed accuracy, probably 1e−6.

This experiment evaluates the published ordinates. Independent certification of the ordinates remains outside its scope.

## Files and replay

`statistic.py` implements distinct triples and batch summaries. `controls.py` supplies independent ensembles and the theoretical control. `run.py` verifies inputs and runs the experiment. `test_statistic.py` checks invariants against independent calculations. `measurements.csv` holds every mean, trim, shift and standard error. `plot_results.py` renders the comparison.

Run in this directory with Python 3, NumPy and SciPy. Matplotlib is required only for the plot. Tested with NumPy 2.4.4, SciPy 1.17.1 and Matplotlib 3.10.8 on macOS.

```sh
export OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 OMP_NUM_THREADS=1
python3 -m unittest -v
python3 run.py --data /absolute/path/to/odlyzko-cache --output measurements.csv
python3 plot_results.py measurements.csv /absolute/path/to/comparison.png
```

Tests cover direct enumeration, thinning of rotated half-grids, crowding ties, circular endpoints, high-altitude unfolding, and an independent integral of the CUE density.

Python handles this bounded experiment with the existing NumPy/SciPy stack. There is no performance claim or benchmark. Rust and a generalized simulation framework are postponed.

This change is isolated to this directory. Rollback consists of reverting its commit. The next step is substantially larger high-altitude samples and further dependence/origin analysis. The arithmetic proof remains a separate research task.
