## A small exact obstruction that can be replayed

For k shifts, an admissible tuple omits a residue class modulo each prime through k. Let S be the set of primes whose conditions are imposed. For each row of this table the listed core is the **unique inclusion-minimal** S for which k points cannot fit inside an interval of diameter D. The finite optimal diameters themselves are known from the MIT tables, attributed there to Engelsma and earlier Clark–Jarvis. No priority claim for the minimal-core refinement is made here.

**Proof and replay.** Translate the minimum to zero. For a normalized tuple, every missing class is nonzero. If 2 is imposed, the grid may be restricted to the even integers; any admissible tuple consists of points of one parity. For each imposed odd prime, branch over a nonzero residue class to delete from the live grid. This covers every possible admissible tuple. If a class is already absent, its unchanged branch contains all other branches. Cut only branches whose number of survivors is below k. The integer-only solver exhausts the displayed cores with no witness. For each row the receipt contains an explicit (k−1)-set obeying its core, a fully admissible k-set at D+2, and a k-set for **each individual removal** q obeying every prime-through-k condition except q. The latter proves every obstruction contains q; since the core alone suffices it is the unique inclusion-minimal obstruction. Parity eliminates the intermediate odd diameter. A separate tiny-instance combination enumeration checks the subset solver for k=2 through 5, all subsets of primes and diameters 0 through 11. Verify from the associated script with `python3 prime_tuple_cores.py`; the output is the full search receipt. [MIT prime-gaps project](https://math.mit.edu/~drew/primegaps.html)

**Implication for further investigation.** Within a single admissible-tuple application of DHL[k,2], keeping 39 or more shifts and searching for different offsets cannot improve 182. The next tuple-size rung is DHL[38,2], which would give 176. A first experiment should evaluate the full 38-coordinate signed form and support restoration, including the improved Type II/III hypotheses from the 182 program. Simply deleting one coordinate from its successful weight preserves neither the integrals nor the positive surplus. The finite obstruction makes no assertion about all methods for bounded gaps.
